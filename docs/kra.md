The core setup of **Learning KRA project**.

KRA objective was to move beyond frontend and build a **backend application using NestJS**, then deploy it end-to-end on AWS. The agreed stack/scope was roughly:

* **NestJS + TypeScript**
* **PostgreSQL + TypeORM**
* REST APIs, DTO validation, modular architecture
* Centralized exception/error handling
* Basic JWT authentication
* Postman for API testing
* Docker/containerization
* **AWS fundamentals + AWS CDK**
* Deployment initially targeting **EC2**
